# PART 06｜회사 자료를 기억하는 AI 지식 창고

## 무엇을 하는 프로그램인가

회사 정책, 상품 정보, 가격표, 수업 자료, 과거 답변처럼 반복해서 찾는 자료를 로컬에서 색인합니다. 검색 결과에는 자료 제목, 출처, 버전, 검토 기한과 실제 근거 문장이 표시됩니다.

이 프로그램은 자료에 없는 내용을 만들어 답하지 않습니다. 검색 근거가 없으면 `검색 결과가 없습니다`와 다음 확인 행동을 표시합니다.

## 빠른 시작

### Mac

1. ZIP 압축을 풉니다.
2. `START_MAC.command`를 더블클릭합니다.
3. 보안 경고가 나오면 파일을 우클릭하고 `열기`를 누릅니다.
4. 브라우저가 열리면 `샘플 자료 넣기`를 누릅니다.
5. `환불 7일`을 검색합니다.

### Windows

1. ZIP 압축을 풉니다.
2. `START_WINDOWS.bat`를 더블클릭합니다.
3. Windows Defender 경고가 나오면 실행 내용을 확인한 뒤 진행합니다.
4. 브라우저에서 샘플 자료를 넣고 검색합니다.

### Linux

```bash
python3 app.py --preflight
python3 -m unittest -v test_unittest.py
python3 app.py
```

## 회사 자료 넣는 방법

### 방법 1. 화면에 직접 붙여넣기

제목, 출처, 검토 기한, 내용을 입력하고 `색인하고 저장`을 누릅니다.

### 방법 2. knowledge 폴더 사용

`knowledge` 폴더에 `.md`, `.txt`, `.csv`, `.json` 파일을 넣고 화면의 `knowledge 폴더 다시 색인`을 누릅니다.

원본 파일은 읽기만 하며 프로그램이 수정하거나 삭제하지 않습니다.

## 정상 완료 기준

- 샘플 자료 3건이 보인다.
- `환불 7일` 검색 결과에 `환불정책.md` 출처가 표시된다.
- 같은 파일을 다시 색인해도 버전이 불필요하게 증가하지 않는다.
- 파일 내용이 바뀌면 버전이 1 증가한다.
- 검토 기한이 지난 자료는 빨간색으로 표시된다.
- 근거 MD를 `output` 폴더로 내보낼 수 있다.
- DB 백업 후 복구했을 때 자료가 다시 나타난다.

## 안전 원칙

- 원본 문서는 수정하지 않습니다.
- 자료에 없는 답은 추측하지 않습니다.
- 검토 기한이 지난 자료는 그대로 사용하지 않고 표시합니다.
- 외부 전송, 공개 발행, 삭제, 계약·가격 확정은 수행하지 않습니다.
- 민감 자료는 별도 폴더와 별도 접근 권한으로 관리합니다.

## 통합 프로그램 호환

`module.json`이 이 PART의 이름, 실행 명령, 포트, 상태 확인 주소와 기능을 설명합니다. 통합 런처는 이 파일을 읽어 모듈을 자동 등록합니다.

## 오류가 생겼을 때

1. 오류 문구 전체를 복사합니다.
2. `python3 app.py --preflight` 결과를 보관합니다.
3. `data`, `knowledge`, `output`, `backups` 폴더를 삭제하지 않습니다.
4. 코딩 AI에게 `AI_AUTOPILOT_PROMPT.md`와 오류 문구를 함께 제공합니다.
5. 수정 후 전체 테스트를 다시 실행합니다.
