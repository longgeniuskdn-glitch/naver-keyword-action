# AGENTS.md

## 목적

이 프로젝트를 수정하는 모든 코딩 AI와 개발자는 아래 규칙을 지킵니다.

## 반드시 지킬 규칙

1. 수정 전에 현재 구조와 변경 계획을 먼저 보고합니다.
2. 사용자의 승인 전에는 코드를 수정하지 않습니다.
3. `data/intake.db`를 삭제하거나 초기화하지 않습니다.
4. 스키마 변경 전 백업과 기존 데이터 호환 계획을 작성합니다.
5. 실제 이메일, 메신저, 환불, 결제, 계약, 삭제와 공개 답변 기능을 임의로 추가하지 않습니다.
6. 개인정보를 로그, 테스트 데이터, 화면과 Git에 넣지 않습니다.
7. 기존 8개 테스트를 삭제하거나 느슨하게 만들지 않습니다.
8. 기능 추가 시 정상·실패·중복·복구 테스트를 함께 추가합니다.
9. 수정 후 `python3 -m unittest -v test_unittest.py`를 실행합니다.
10. 변경 파일, 이유, 테스트와 미검증 항목을 `CHANGELOG.md`에 기록합니다.

## 기본 작업 순서

```text
분석 → 계획 → 사람 승인 → 작은 수정 → 테스트 → 화면 확인 → 변경 기록 → 백업
```

## 완료로 말할 수 없는 경우

- 테스트를 실행하지 않았음
- Linux 새 폴더에서 검증하지 않았음
- Mac·Windows 실행기는 있지만 실제 운영체제에서 확인하지 않았음
- 외부 서비스 연결 코드를 작성했지만 실제 계정에서 확인하지 않았음
