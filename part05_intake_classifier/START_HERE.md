# PART 05 업무 접수·분류실 — START HERE

## 이 프로그램이 하는 일

이메일, 문의폼, 채팅, 메모와 CSV에서 들어온 업무를 한 화면에 등록하고 다음 항목으로 분류합니다.

- 문의 유형
- 긴급도
- 담당 팀
- 위험 표시
- 사람 승인 필요 여부
- 처리 상태

실제 메일 답장, 환불, 결제, 계약 확정이나 외부 게시를 실행하지 않습니다.

## 10분 첫 실행

### macOS

1. 압축을 풉니다.
2. `START_MAC.command`를 더블클릭합니다.
3. 보안 경고가 나오면 Finder에서 파일을 우클릭하고 **열기**를 선택합니다.
4. 브라우저에서 `http://127.0.0.1:8795`가 열리는지 확인합니다.

### Windows

1. 압축을 풉니다.
2. `START_WINDOWS.bat`를 더블클릭합니다.
3. 브라우저에서 `http://127.0.0.1:8795`가 열리는지 확인합니다.

### Linux 검증 명령

```bash
python3 -m unittest -v test_unittest.py
python3 app.py --preflight
python3 app.py --no-browser
```

## 첫 mock 흐름

1. **샘플 넣기**를 누릅니다.
2. 배송 문의가 `배송 / 물류 / low`로 분류되는지 확인합니다.
3. 긴급 환불이 `환불·취소 / prepare_only / high`로 분류되는지 확인합니다.
4. 계약 분쟁이 `계약·법무 / human_only`로 분류되는지 확인합니다.
5. 한 항목의 **분류 승인**을 누릅니다.
6. CSV 내보내기를 실행합니다.
7. DB 백업을 내려받습니다.
8. 같은 접수 내용을 다시 넣어 중복이 차단되는지 확인합니다.

## 자동 테스트

```bash
python3 -m unittest -v test_unittest.py
```

정상 결과는 `Ran 8 tests`와 `OK`입니다.

## 사전 점검

```bash
python3 app.py --preflight
```

`ready: true`이면 Python, SQLite 데이터 폴더와 8795 포트를 사용할 수 있습니다.

## 백업과 복구

```bash
python3 app.py --backup
python3 app.py --restore backups/백업파일.db
```

백업 파일이 존재하는 것만으로 완료가 아닙니다. 복구 후 앱을 다시 열어 이전 접수 항목과 상태가 보이는지 확인합니다.
