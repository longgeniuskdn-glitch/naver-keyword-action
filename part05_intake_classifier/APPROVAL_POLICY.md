# APPROVAL POLICY

## 기본 원칙

이 앱의 분류 결과는 제안입니다. 실제 답변, 환불, 송금, 계약, 공개 게시와 개인정보 처리는 사람이 결정합니다.

## 처리 모드

### standard — 분류 후 사람 승인

- 배송
- 제품 사용법
- 일반 제휴 제안
- 일반 예약 문의

분류와 담당을 사람이 확인한 뒤 승인합니다.

### prepare_only — AI 준비만 가능

- 환불·보상
- 결제·송금
- 개인정보 포함
- 외부 공개 답변
- 긴급 항목

AI는 분류·요약·답변 초안까지만 준비할 수 있습니다. 실제 행동은 사람이 합니다.

### human_only — 사람 직접 처리

- 계약 확정
- 법률 판단
- 분쟁 대응
- 내용증명

코딩 AI가 결론을 내리거나 자동 처리하지 않습니다.

## 첫 10건 운영

각 항목마다 다음을 기록합니다.

- 원래 채널과 접수 시각
- 자동 분류 결과
- 사람이 바꾼 분류와 이유
- 긴급도 변경 여부
- 담당 변경 여부
- 개인정보 포함 여부
- 최종 처리 시간
- 누락·중복 여부

같은 수정이 두 번 이상 반복되면 분류 규칙을 변경하되, 기존 테스트와 새 회귀 테스트를 함께 실행합니다.
