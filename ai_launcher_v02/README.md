# 우리 회사 AI 운영실 v0.2

PART별 독립 프로그램을 한 화면에서 탐색·실행·종료하고 상태와 로그를 확인하는 로컬 통합 런처입니다.

## 포함 모듈

- PART 04｜AI 자동화 진단실
- PART 05｜업무 접수·분류실
- PART 06｜회사 자료를 기억하는 AI 지식 창고

각 모듈의 데이터베이스와 핵심 로직은 분리되어 있습니다. 런처가 한 프로그램의 데이터를 다른 프로그램으로 옮기거나 합치지 않습니다.

## 실행

### macOS

`START_MAC.command`를 더블클릭합니다. 보안 경고가 나오면 Finder에서 우클릭 후 **열기**를 선택합니다.

### Windows

`START_WINDOWS.bat`를 더블클릭합니다.

### Linux

```bash
chmod +x START_LINUX.sh
./START_LINUX.sh
```

기본 런처 주소는 `http://127.0.0.1:8780`입니다. 포트가 사용 중이면 8781부터 사용 가능한 포트를 자동으로 찾습니다.

## 버튼의 의미

- **실행**: 선택한 PART 프로그램만 시작합니다.
- **종료**: 선택한 PART 프로그램만 종료합니다.
- **화면 열기**: 해당 프로그램의 로컬 화면을 새 탭에서 엽니다.
- **전체 실행**: 등록된 모듈을 순서대로 시작합니다. 한 모듈이 실패해도 나머지 모듈은 계속 시도합니다.
- **전체 종료**: 등록된 모듈을 역순으로 종료합니다.

## 데이터와 로그

- 모듈 데이터: `modules/각모듈/data/`
- 모듈별 결과물: `modules/각모듈/output/`
- 모듈별 백업: `modules/각모듈/backups/`
- 런처 실행 로그: `logs/모듈ID.log`
- 런처 PID 상태: `runtime/pids.json`

## 직접 점검

```bash
python3 launcher.py --list
python3 -m unittest -v test_launcher.py
```

## 현재 통합 범위

v0.2는 프로그램의 실행·종료·상태·포트·로그를 통합합니다. 공통 승인 대기열, 공통 고객 카드, 공통 ROI와 모듈 간 자동 데이터 전달은 다음 단계이며 아직 구현하지 않았습니다.
